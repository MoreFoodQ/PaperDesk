# PaperDesk product context

## Register
Product: a local desktop and browser research reading workbench.

## Users and purpose
Readers import PDF and supported EPUB documents, translate passages, ask questions,
and keep notes attached to the original content.

## Interface principles
- Preserve the existing graphite and cyan palette, system typography and controls.
- Use Traditional Chinese terminology, with an English interface available.
- Explain model processing choices and preserve existing reading data.
- Keep settings keyboard accessible and usable at narrow window widths.
- Prefer clear actions and task feedback over decorative presentation.
